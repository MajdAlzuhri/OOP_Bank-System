# Banking & Currency Exchange System (C++)

## Description
A C++ console-based application that simulates a banking system combined with currency exchange functionality. The project is built using Object-Oriented Programming (OOP) and follows SOLID principles to ensure clean and maintainable code.

---

## Features
- Account creation and management
- Deposit and withdrawal operations
- Transfer between accounts
- Currency exchange system (multiple currencies)
- File handling for saving and loading data
- User-friendly console interface

---

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- SOLID Principles
- File Handling
